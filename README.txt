GitHub Pages 公開用ファイル一式

■ 内容物
・index.html … アプリ本体
・icon.png / icon-512.png … ホーム画面用アイコン

■ 公開手順（GitHubのWeb画面から）
1. 新しいリポジトリを作成します（名前の例：story-english-writing）。
2. この3つのファイルをリポジトリ直下にアップロードします。
3. Settings → Pages で、公開元ブランチ（main）とルートを指定します。
4. 発行されたURLをiPhoneのSafariで開き、「ホーム画面に追加」すると
   アプリのように使えます。

■ 使い方
ブラウザで開くだけで使えます。学習記録は端末のブラウザ内に保存されます。
詳しい練習の流れは、アプリ内ホーム画面の「使い方」にあります。
